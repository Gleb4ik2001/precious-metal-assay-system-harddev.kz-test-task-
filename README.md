# Система учета проб драгоценных металлов (Backend REST API)

Прототип backend-сервиса для автоматизации процессов учета, валидации и аналитической отчетности проб драгоценных металлов с интеграцией симулятора внешнего лабораторного оборудования.

## Технологический стек
* **Язык разработки:** Python 3.13 (Slim-образ для Docker)
* **Фреймворк:** FastAPI
* **ORM & БД:** SQLAlchemy + Alembic + SQLite
* **Валидация данных:** Pydantic
* **Тестирование:** Pytest + TestClient
* **Контейнеризация:** Docker, Docker Compose

## Перед запуском создайте файл ```.env``` в корневом каталоге проекта со следующими параметрами:
```env
DATABASE_URL=sqlite:///./samples.db
SQLALCHEMY_DATABASE_URL=sqlite:///./test.db
API_URL=http://localhost:8000/samples
```
## Запуск через Docker Compose
Выполните команду сборки и запуска контейнеров:
```bash
docker-compose up --build
```
API будет доступно по адресу: ```http://localhost:8000```

Интерактивная документация (Swagger UI): http://localhost:8000/docs

## Автоматическое тестирование
Тестирование реализовано на фреймворке ```pytest``` с использованием ```TestClient```. Благодаря механизму ```dependency_overrides``` в tests/conftest.py, выполнение тестов полностью изолировано в тестовой базе данных test.db. Таблицы автоматически пересоздаются (drop_all / create_all) перед каждым тест-кейсом, гарантируя стопроцентную воспроизводимость и независимость тестов друг от друга.

### Покрытые сценарии (tests/test_samples.py):
1. ```test_create_sample``` - успешное создание пробы (проверка статус-кода 201 Created и автоматического присвоения статуса created).
2. ```test_create_sample_with_negative_weight``` - валидация веса (проверка возврата кода 422 Unprocessable Entity при отрицательном значении веса).
3. ```test_get_samples``` - проверка успешного получения списка всех зарегистрированных проб.
4. ```test_update_sample_status``` - частичное обновление статуса пробы на approved.
5. ```test_summary_report``` - проверка корректности расчета математических метрик (минимальный, максимальный, средний вес и группировка по статусам) в аналитическом отчете.

### Запуск тестов локально:
```bash
python -m pytest -v
```

### Запуск тестов внутри Docker-контейнера:
```bash
docker-compose exec api python -m pytest -v
```
